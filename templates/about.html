About Project

Project Overview

This project is an IoT-based Fire Detection and Monitoring System built using ESP32 and Flask. It continuously monitors temperature, humidity, and fire conditions in real time.

Sensor data is sent from the ESP32 device to the Flask backend through HTTP APIs and stored in a database. The dashboard displays live updates and alerts users immediately when fire is detected.

Features

  • Real-time temperature monitoring
  • Humidity tracking
  • Fire detection system
  • Live dashboard updates
  • Sound alarm and push notifications
  • User login and authentication

Technologies Used

  • ESP32 Microcontroller
  • Flask (Python Backend)
  • SQLite Database
  • HTML, CSS, Bootstrap
  • JavaScript (for real-time updates)
  • OneSignal (push notifications)
